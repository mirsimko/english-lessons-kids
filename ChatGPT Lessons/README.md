# ChatGPT voice-mode lessons

> [!warning] AI-generated content
> ⚠️ Most of this content was generated by a large language model (AI) and reviewed only lightly. Check it before relying on it.

Ready-to-paste prompts that turn ChatGPT's voice mode into a playful Jolly Phonics teacher for two children: one around 2 and one around 4.

## How to use
1. Open the prompt for today's sound below and copy the text inside the code block.
2. Replace `[OLDER CHILD NAME]` and `[YOUNGER CHILD NAME]` with your children's first names (do this on your device only, never commit real names to this public repo).
3. Open the ChatGPT app and start a **new chat**. Paste the prompt as a **text** message and send it.
4. Tap the **voice** button to switch the same chat to voice mode. Say "Let's start!".
5. Sit with the children, do the actions with them, and help them answer. Pause or interrupt any time.

Tips: use a speaker, keep it short, stop while it's fun, and follow the [[Weekly rhythm]] (one new sound per day, repeat the set next week). An adult should always be present.
